# KALISTA — Kaldik Assistant

Pemulihan proyek dari artefak pengembangan terdahulu.

- `src/App.tsx`: source Kalista V1.1 (14 Juli 2026)
- `archive/Kalista_Pro_2.2_Mobile_Optimized.tsx`: snapshot Kalista Pro 2.2
- `archive/Kaldik_Assistant_Landing_MVP.html`: landing page historis

## Menjalankan

```bash
npm install
npm run dev
```

Build: `npm run build`.

Konfigurasi Vite/Tailwind ditambahkan untuk pemulihan. Belum dilakukan pengujian regresi atau verifikasi build, dan aset screenshot landing belum tersedia. Jangan anggap rilis produksi stabil.
